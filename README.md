# ✈️ Jet Engine Predictive Maintenance

## GRU-Based Remaining Useful Life Prediction with LangGraph

A predictive maintenance system for estimating the Remaining Useful Life (RUL) of jet engines using the NASA C-MAPSS FD001 dataset.

The project combines:

- Data preprocessing
- Sensor analysis
- Deep learning
- GRU-based RUL prediction
- SHAP-based feature importance
- Streamlit
- LangGraph
- Agent-based interpretation
